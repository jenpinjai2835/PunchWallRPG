# รู้จัก Smash Wall และทิศทางที่เรากำลังพัฒนา

Smash Wall เป็นเกมฝึกพลังแล้วต่อยทำลายกำแพง เพื่อหาเหรียญ เปลี่ยนหมัด สะสมสัตว์เลี้ยง และเปิดทางไปยังชั้นที่ยากขึ้น จุดสนุกที่ตกลงกันคือ **ต่อยแล้วรู้สึกสะใจ และช่วยกันเล่นกับเพื่อนได้** โดยมีของสะสมและการเติบโตของตัวละครเป็นเป้าหมายต่อเนื่อง

**เริ่มเล่นอย่างไร**

1. **ลองต่อยกำแพงด้านหน้า** เข้าใกล้ เล็งไปยังบล็อก แล้วกดปุ่มต่อย ดูแถบพลังชีวิตของเป้าหมายและจำนวนครั้งโดยประมาณที่ต้องต่อย กำแพงแต่ละวัสดุแข็งไม่เท่ากัน จึงต้องพัฒนาพลังเมื่อไปลึกขึ้น
2. **ฝึกเมื่ออยากเพิ่ม Power** เดินไปยังจุดฝึก เช่น Rookie Power Bag แล้วเริ่มฝึกจากปุ่มที่ปรากฏใกล้จุดนั้น ขณะฝึกจะเห็นพลังที่ได้รับ กด **EXIT** เพื่อกลับไปเดินและต่อย จุดฝึกที่สูงขึ้นมีเงื่อนไขพลังของตัวเอง
3. **ต่อยเพื่อเปิดทางและรับรางวัล** เมื่อบล็อกแตก เหรียญและคะแนนคำนวณจากส่วนร่วมในการทำดาเมจ ส่วน XP ของบล็อกและเครดิตความลึกให้ผู้ร่วมทำดาเมจตามกติกาเต็มของบล็อก จึงช่วยกันทำลายเป้าหมายเดียวกับเพื่อนได้ ความลึกที่เคยไปถึงเป็นอีกเป้าหมายของตัวละคร
4. **นำสิ่งที่ได้มาพัฒนาตัวเอง** เปิด Shop เพื่อดูหมัดที่ซื้อไหว อ่านรายละเอียดบนการ์ดแล้วซื้อหรือสวมใส่ หมัดแรกที่บทสอนชี้ให้ซื้อคือ Street Boxing Fist ต้องถึง **Depth 1 และมี 180 Coins** ส่วนไข่สัตว์เลี้ยงมีโอกาสดรอปจากการทำลายกำแพง เก็บแล้วเปิดคลังเพื่อเลือกตัวที่ต้องการใช้งาน การ Fusion ใช้สัตว์ชนิดและระดับดาวตามเงื่อนไขเพื่อเพิ่มดาว จึงควรอ่านจำนวนที่ต้องใช้ก่อนยืนยัน
5. **เลือกเป้าหมายรอบต่อไป** อาจเป็นหมัดใหม่ สัตว์เลี้ยงที่ดีขึ้น ชั้นวัสดุถัดไป หรือ Rebirth เมื่อพร้อม เส้นทางลึกสุดนำไปสู่บอส Titan ซึ่งปัจจุบันต้องมี **Wall Level 99 และผ่าน Depth 75** จึงโจมตีได้ หน้าจอบอสแสดง HP ช่วงการต่อสู้ และเวลารอกลับมาเมื่อถูกกำจัด

**เมนูไหนใช้ทำอะไร**

| เมนู | ใช้เมื่อ |
| --- | --- |
| **Shop** | อ่านชื่อ ค่าสถานะ ราคา และเงื่อนไขบนการ์ดสินค้า แล้วซื้อหรือสวมใส่ หน้าสินค้า Premium, Boosts, Honor และ Robux แยกตามประเภท |
| **Inventory / Pets** | ค้นหาและกรองของที่มี เลือกดูโมเดลกับรายละเอียด แล้วสวมหมัด จัดทีมสัตว์เลี้ยง หรือใช้คำสั่งที่มีสำหรับของชิ้นนั้น บนมือถือใช้ปุ่มย้อนกลับจากรายละเอียดเพื่อกลับมาที่รายการ |
| **Quests / Daily** | เปิดหน้าภารกิจและรางวัล ดูเงื่อนไขแล้วกดรับเมื่อทำครบ เช่น รางวัลรายวัน การทำลายกำแพง และเวลาเล่น |
| **Rebirth** | ตรวจเงื่อนไขและสิ่งที่จะถูกรีเซ็ตก่อนยืนยัน เพื่อแลกกับตัวคูณพลังถาวร |
| **Honor** | ดูของที่แลกด้วย Honor และเงื่อนไขปลดล็อก เช่น ความลึกหรือจำนวน Rebirth โดย Honor มีรางวัลจากความก้าวหน้าและการเคลียร์บอสที่เข้าเกณฑ์ |
| **Settings** | เปิด–ปิดเสียง เลือก **CALM** เพื่อลดการเคลื่อนไหว และปรับขนาด UI ให้เหมาะกับจอ |
| **Spin** | ดูสิทธิ์หมุนและรางวัล ใช้ได้เมื่อเงื่อนไขหรือเวลารอครบ |

Rebirth มีผลกับความก้าวหน้าบางส่วน: **Power กลับเป็น 25, Coins เป็น 0, Wall Level เป็น 1 และ Wall XP เป็น 0** พร้อมเปลี่ยนหมัดที่สวมเป็น Starter Fist และหยุดการฝึก ต่างจากผู้เล่นใหม่ที่เริ่ม Power 15 แต่ความลึกที่บันทึกไว้ หมัดที่เป็นเจ้าของ สัตว์เลี้ยง และ Honor ยังคงอยู่ หมัดที่ซื้อไว้จึงเลือกกลับมาสวมได้ ควรอ่านหน้าสรุป Rebirth ทุกครั้ง เพราะเงื่อนไขรอบถัดไปเพิ่มตามจำนวนครั้งที่ทำ

**สิ่งที่ปรับปรุงในรอบนี้แล้ว**

- ปรับ Shop และ Inventory ให้รายการกับรายละเอียดอ่านง่ายขึ้นบนมือถือ แก้พื้นที่ขอบจอและการวางปุ่ม รวมถึงรักษาของที่เลือก คำค้น และตำแหน่งเลื่อนระหว่างใช้งาน
- ทำรูปทรงเฉพาะของหมัดห้ารุ่นแรกให้ใช้ร่วมกันในร้าน คลัง และตอนสวมจริง ได้แก่ Starter Fist, Street Boxing Fist, Iron Crusher Fist, Thunder Core Fist และ Titan Siege Fist พร้อมปรับการวางที่ข้อมือและภาพตัวอย่าง
- แก้การเลือกเป้าหมายและการแสดง HP/จำนวนหมัดของกำแพง รวมถึงข้อมูลบอส ปรับกล้องเมื่อเจอผนังหรือสิ่งกีดขวาง และการคืนมุมกล้องเมื่อเปิดเมนู ฝึก หรือเกิดใหม่
- ลดงานอัปเดตข้อมูลและหน้าจอที่ซ้ำโดยไม่จำเป็น แก้ปุ่ม Settings ถูกสร้างใหม่ระหว่างรอคลิก และแก้เงื่อนไขความลึกของบอสให้ตรงกับการเล่นจริง
- ลดกรอบและแสงตกแต่งของร้านค้าและกระเป๋า ใช้โทนพื้นเดียวกัน แยกสถานะสวมอยู่จากปุ่มที่กดได้ และย่อพื้นที่เป้าหมายกับแถบเลือดให้เห็นฉากเล่นมากขึ้น
- แก้ไข่ดรอปที่ขวางการพุ่งต่อย และปรับการจัดทีมสัตว์เลี้ยงตอนซูมใกล้บนจอแคบ เพิ่มหู อุ้งเท้าและปลอกคอให้ Forest Pup อ่านรูปทรงได้ชัดขึ้นทั้งในคลังและตอนเดินตาม
- หน้าร้านบนหน้าต่างคอมพิวเตอร์ที่แคบใช้รายการเต็มแถว เว้นขอบจอและรักษาขนาดตัวอักษร พร้อมจัดปุ่มต่อยขึ้น–ลงให้แยกกันชัดเจน

รายการนี้หมายถึงการเปลี่ยนแปลงที่รวมอยู่ในรุ่นทดสอบปัจจุบัน การตรวจรวมทั้งเกมยังดำเนินอยู่ จึงยังไม่ใช่คำยืนยันว่าไฟล์สำหรับปล่อยจริงพร้อมแล้ว หรือทุกอุปกรณ์จะลื่นเท่ากัน

**แนวทางทำให้คนอยากกลับมาเล่น — ยังเป็นงานต่อไป**

เริ่มจากช่วงเปิดเกมให้เข้าใจง่าย: รู้ว่าจะต่อยตรงไหน ฝึกเมื่อไร และกำลังเก็บเงินเพื่ออะไร จากนั้นทดสอบจังหวะการเติบโตทั้งช่วงต้น กลาง และท้าย โดยเฉพาะรอยต่อที่กำแพงแข็งขึ้นมากกับราคาหมัดระดับสูง แล้วจึงออกแบบให้การช่วยเพื่อนและผลงานร่วมกันมองเห็นได้ชัดขึ้น

ข้อเสนอเหล่านี้ยังไม่ได้กลายเป็นโหมดใหม่หรือการปรับราคาและรางวัลทั้งเกม ต้องใช้ผลจากผู้เล่นใหม่ การเล่นหลายคน และมือถือจริงมาช่วยตัดสินใจ เป้าหมายคือให้การต่อยสนุก ใช้เมนูง่าย และมีเป้าหมายที่ไปถึงได้ จนผู้เล่นอยากชวนเพื่อนหรือแชร์ด้วยตัวเอง ความเป็นไวรัลรับประกันไม่ได้ แต่เราตรวจและพัฒนาคุณภาพเหล่านี้ได้
